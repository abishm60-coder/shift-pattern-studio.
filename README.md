# Shift Pattern Studio Website

Premium futuristic multi-page website for Shift Pattern Studio - Web Design & Development Agency.

## Pages
- Home (index.html)
- About (about.html)
- Services (services.html)
- Portfolio (portfolio.html)
- Project Detail (project.html)
- Pricing (pricing.html)
- Contact (contact.html)
- Privacy Policy (privacy.html)
- Terms & Conditions (terms.html)

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Orbitron, Space Grotesk, Montserrat, Inter)
- Font Awesome 6 (CDN)

## Features
- Fully responsive design
- Glassmorphism effects
- Scroll reveal animations
- Dynamic portfolio filtering
- Dynamic project detail loading via URL params
- Contact form with validation
- WhatsApp integration throughout
- SEO optimized with meta tags
- Accessibility friendly (semantic HTML, keyboard nav, focus states)
- prefers-reduced-motion support

## How to Use
Simply open `index.html` in any modern web browser. No server or build process required.
